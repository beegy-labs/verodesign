# Task: X3 Round 4-C — Optional group fallback emission (build-time)

X2-1 SDD 가 `status` / `finance` / `aaa-strict` 를 optional group 으로 정의 → `implements` 안 한 brand 의 components 가 `--vds-theme-status-*` / `--vds-theme-destructive-*` 참조시 변수 미정의로 깨짐.

**근본 해결책 = build-time fallback emission**: 컴포넌트 src 는 그대로(깨끗) 두고, 빌드 파이프라인이 brand 의 `implements` 따라 emit 결정.

## Why build-time emission > CSS-level component fallback

| 옵션 | 분산도 | 새 컴포넌트 추가시 | 새 brand 추가시 | 정책 변경시 |
|------|--------|--------------------|------------------|-------------|
| CSS fallback (58 ref site) | 58 site | site 마다 fallback 추가 (오류 가능) | brand 무관 | 58 site 갱신 |
| Build-time emission (1 source) | 1 site | site 무변경 | implements 선언만 | 1 site 갱신 |

build-time emission = brand 1000 확장성 OK. **본 task = build-time emission 구현.**

## 정책 결정 (build-time emission rule)

각 optional group + slot 마다 다음 emission 규칙:

| Slot | 기본 emission (brand 가 group implements 안 함) |
|------|----------------------------------------------|
| `--vds-theme-status-success` | `var(--vds-theme-primary)` |
| `--vds-theme-status-success-foreground` | `var(--vds-theme-primary-foreground)` |
| `--vds-theme-status-error` | `var(--vds-theme-primary)` |
| `--vds-theme-status-error-foreground` | `var(--vds-theme-primary-foreground)` |
| `--vds-theme-status-warning` | `var(--vds-theme-primary)` |
| `--vds-theme-status-warning-foreground` | `var(--vds-theme-primary-foreground)` |
| `--vds-theme-status-info` | `var(--vds-theme-primary)` |
| `--vds-theme-status-info-foreground` | `var(--vds-theme-primary-foreground)` |
| `--vds-theme-status-neutral` | `var(--vds-theme-text-secondary)` |
| `--vds-theme-status-neutral-foreground` | `var(--vds-theme-bg-page)` |
| `--vds-theme-destructive` | `var(--vds-theme-primary)` |
| `--vds-theme-destructive-foreground` | `var(--vds-theme-primary-foreground)` |

원칙:
- 모든 status semantic → primary (semantic distinction 손실 = brand 선택 결과)
- neutral 만 text-secondary (semantic 으로 "neutral grey" = secondary text 와 가장 가까움)
- destructive → primary (destructive 도 status 와 같은 group 으로 처리)

**visual outcome**: status 미bind brand 에서 컴포넌트의 success/warning/error/info tone 이 primary 색상 ("brand 가 status 의미 없으므로 single emphasis").

## 작업

### 1. fallback emission 모듈

`packages/design/src/build/optional-group-fallback.mjs` 신설 (또는 기존 emit 코드의 자연스러운 위치에 통합):

```js
// 입력: 현 brand 의 implements list
// 출력: brand 가 안 한 optional group 들의 alias CSS rules
export const OPTIONAL_GROUP_FALLBACKS = {
  status: {
    '--vds-theme-status-success': 'var(--vds-theme-primary)',
    '--vds-theme-status-success-foreground': 'var(--vds-theme-primary-foreground)',
    '--vds-theme-status-error': 'var(--vds-theme-primary)',
    '--vds-theme-status-error-foreground': 'var(--vds-theme-primary-foreground)',
    '--vds-theme-status-warning': 'var(--vds-theme-primary)',
    '--vds-theme-status-warning-foreground': 'var(--vds-theme-primary-foreground)',
    '--vds-theme-status-info': 'var(--vds-theme-primary)',
    '--vds-theme-status-info-foreground': 'var(--vds-theme-primary-foreground)',
    '--vds-theme-status-neutral': 'var(--vds-theme-text-secondary)',
    '--vds-theme-status-neutral-foreground': 'var(--vds-theme-bg-page)',
    '--vds-theme-destructive': 'var(--vds-theme-primary)',
    '--vds-theme-destructive-foreground': 'var(--vds-theme-primary-foreground)',
  },
  // finance / aaa-strict 도 추후 필요시 추가
};

export function emitOptionalGroupFallbacks(implementsList) {
  const rules = [];
  for (const [group, vars] of Object.entries(OPTIONAL_GROUP_FALLBACKS)) {
    if (implementsList.includes(group)) continue;
    for (const [name, value] of Object.entries(vars)) {
      rules.push({ name, value });
    }
  }
  return rules;
}
```

### 2. brand css emit 통합

기존 emit 단계에서 brand 별 css 산출 끝부분에 위 fallback rules 추가. brand 가 status implements 안 함 → fallback rules emit; implements 함 → fallback rules emit 안 함 (canonical 가 emit 됨).

검증:
- `packages/design/dist/css/themes/verobase.css` 안에 `--vds-theme-status-success: var(--vds-theme-primary)` 같은 alias rule 존재
- `packages/design/dist/css/themes/girok.css` 안에는 fallback rule 없음 (canonical emit)
