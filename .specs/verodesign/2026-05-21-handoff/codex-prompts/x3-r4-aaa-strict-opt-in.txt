### 2. `*-strong` slot binding 평가 + 필요시 overrides 추가

aaa-strict.json 의 `*-strong` slot 은 default 가 `{theme.X}` 별칭 → AA baseline 값 그대로. AAA 7:1 통과는 brand 별 실제 색상에 따라 다름.

girok 의 다음 slot 들이 AAA 7:1 통과하는지 build/audit 로 확인 후 통과하지 않는 것만 override:
- `theme.text.primary-strong` (vs `theme.bg.page` / `theme.bg.card`)
- `theme.text.secondary-strong` (vs `theme.bg.card`)
- `theme.primary-strong` (background slot; foreground 와 7:1)
- `theme.status.{success,error,warning,info,neutral}-strong` (각각 foreground 와 7:1)

approach:
1. 먼저 `aaa-strict` 추가만 하고 빌드 → audit 가 어느 slot 이 fail 인지 보고
2. fail 한 slot 만 girok-light/dark 의 theme 파일에서 `theme.X-strong` 또는 그 foreground 를 AAA 색상으로 override

override 예시 (girok-light 의 walnut text 기반):
```json
"text": {
  "primary-strong": {
    "$value": "oklch(15% 0.02 80)",  // 더 어둡게
    "$type": "color"
  }
}
```

target 7:1 미달 slot 만 최소 override. 통과하는 slot 은 alias 그대로.

### 3. WCAG audit 통과 + report 산출 확인

```sh
pnpm --filter @verobee/design build

# contrast-report 안 girok 의 aaa-strict tier pair 존재 확인
node -e "
const r = require('./packages/design/dist/data/contrast-report.json');
const girok = r.girok;
let aaaCount = 0;
for (const mode of ['light','dark']) {
  for (const [pair, info] of Object.entries(girok[mode] ?? {})) {
    if (info.required === 'AAA-strict' || info.required === 'AAA' || info.tier === 'aaa-strict' || pair.includes('strong')) {
      aaaCount++;
    }
  }
}
console.log('girok AAA-strict pairs:', aaaCount);
"
```

aaaCount > 0 = PASS.

